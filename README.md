# 云图书馆小程序

基于原生微信小程序和微信云开发实现的图书借阅示例，包含图书检索、详情、借阅、归还、我的借阅、图书维护和示例数据初始化。

## 目录

- `miniprogram/`：小程序端页面和样式
- `cloudfunctions/`：云函数
- `project.config.json`：微信开发者工具项目配置

## 云开发准备

1. 使用微信开发者工具导入本目录。
2. 开通云开发环境，将环境 ID 填入 `miniprogram/app.js` 的 `globalData.envId`。
3. 在云开发控制台创建集合：
   - `users`
   - `books`
   - `borrowRecords`
4. 上传并部署云函数：
   - `login`
   - `users`
   - `books`
   - `borrow`
   - `initData`
5. 第一个登录系统的用户会自动成为管理员。
6. 在“管理”页点击“初始化示例数据”，即可写入 3 本示例图书。

## 数据集合建议权限

建议将 `books`、`borrowRecords`、`users` 集合设置为“仅创建者及管理员可读写”或自定义安全规则；本项目的关键读写都经由云函数完成，生产环境应继续收紧管理端入口和写权限。

## 功能说明

- 图书页：搜索书名、作者、ISBN，筛选可借图书。
- 详情页：查看馆藏、库存、简介并借阅。
- 我的页：查看借阅中/待确认/已归还记录，并提交归还申请。
- 管理页：管理员可新增、删除图书，设置用户为管理员，确认归还申请，并查看所有人的借阅记录。
